# Чек-лист функционального тестирования SignalGenerationProgram

## 1. Блок: Валидация ввода
- [ ] Проверка доступности ввода в поля: "Амплитуда (A) (*.*)", "Частота (f) (*.*)", "Кол-во точек (от 100-10000)";
- [ ] Проверка ввода граничного значения количества точек: нижняя граница (100 точек);
- [ ] Проверка ввода граничного значения количества точек: верхняя граница (10 000 точек);
- [ ] Валидация невалидного значения количества точек ниже нормы: диапазон < 100 точек;
- [ ] Валидация невалидного значения количества точек выше нормы: диапазон > 10000 точек;
- [ ] Проверка ввода пустых значений во все три поля параметров;
- [ ] Проверка ввода буквенных символов и спецсимволов в числовые поля;
- [ ] Проверка ввода дробных чисел через точку и через запятую.

## 2. Блок: Генерация сигналов
- [ ] Проверка успешного переключения типов сигналов в выпадающем списке;
- [ ] Расчёт математических характеристик для сигнала типа "Синусоида";
- [ ] Расчёт математических характеристик для сигнала типа "Меандр";
- [ ] Проверка корректности расчёта поля "Максимум";
- [ ] Проверка корректности расчёта поля "Минимум";
- [ ] Проверка корректности расчёта поля "Среднее значение";
- [ ] Стресс-тестирование: стабильность расчёта при вводе максимальных массивов данных от 7000 точек.

## 3. Блок: График сигналов
- [ ] Доступность кнопки построения графика до генерации сигнала;
- [ ] Успешное открытие окна «График сигналов» по нажатию кнопки после генерации;
- [ ] Отображение координатной сетки и кривой сигнала внутри графического окна;
- [ ] Проверка физических размеров элемента графика на экране.

## 4. Блок: Сохранение в файл и Сохранение в БД
- [ ] Поведение системы при попытке нажать кнопки сохранения до генерации сигнала;
- [ ] Создание физического CSV-файла в папке `SaveData` после успешного экспорта;
- [ ] Соответствие имени CSV-файла динамическому паттерну из ТЗ;
- [ ] Проверка структуры CSV-файла: наличие метаданных в первых 5 строках, разделителей и корректных точек;
- [ ] Создание и инициализация файла базы данных SQLite `signals.db` в папке `DataBase`;
- [ ] Проверка физической записи строк в таблицу базы данных `SignalPoints`.

## 5. Блок: Очистка формы
- [ ] Сброс всех текстовых полей ввода параметров при нажатии кнопки «⎚»;
- [ ] Сброс полей результатов расчётов при очистке;
- [ ] Полное удаление строк из таблицы `points_data_grid` после клика на кнопку «⎚».
