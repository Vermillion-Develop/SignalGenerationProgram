# Автоматизированные UI-тесты для SignalGenerationProgram

Репозиторий содержит комплект автоматизированных UI и интеграционных автотестов, а также полный набор QA-документации для производственной практики.

## Стек технологий тестов
* **Платформа:** C# (.NET 10.0-windows)
* **Тестовый фреймворк:** NUnit 4
* **Инструмент автоматизации UI:** FlaUI.Core + FlaUI.UIA3
* **Работа с БД:** Microsoft.Data.Sqlite

## Документация в репозитории
* `Дмитрий_QA_Тест_Кейсы.docx` — Итоговый Word-документ с подробными таблицами 18 тест-кейсов, ручными проверками и скриншотами.
* `CHECKLIST.md` — Функциональный чек-лист проверок приложения.
* `BUG_REPORT.md` — Отчет по дефектам и аудит качества кода.
* `TEST_PLAN.md` — Тест-план и примененные техники тест-дизайна.

## Инструкция по сборке и запуску автотестов

### Предусловия
* Установлена **Visual Studio 2026**.
* Операционная система **Windows 10 / 11**.

### Запуск тестов
1. Откройте файл решения `SignalGenerationProgram.slnx` в Visual Studio 2026.
2. Выполните пересборку проекта: **Сборка -> Пересобрать решение** (`Ctrl + Shift + B`).
3. Откройте панель: **Тест -> Обозреватель тестов**.
4. Выберите тесты **TestNUnit_QA** .
5. Нажмите кнопку **Запустить все** .
